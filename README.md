## Project

MeetingScheduler

## Project Description

A program that automatically schedules optimal meeting times based off of individual prefrences.

When a meeting needs to be scheduled, the user selects who they want to attend the meeting, the program will then show a set of times
that work for all selected individuals or the times that work for most people in the case that not all preferences overlap in some way.

## Features

1. User DataCard Page:
   A persons datacrad includes their name, an ID, and the various time preferrences they have

2. Instruction Page:
   A page in the program which contains instructions for the programs use

3. Scheduler Page:
   A page where the user can create various schedules basef on preference. Options include: selecting specific individuals or all people for scheduling,
   selecting different times and weekdays, and limiting the number of schedules to be displayed
