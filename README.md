## Project

Meeting Scheduler

## Project Description

A program that automatically schedules optimal meeting times based off of individual preferences.

When a meeting needs to be scheduled, the user selects who they want to attend the meeting, the program will then show a set of times
that work for all selected individuals or the times that work for most people in the case that not all preferences overlap in some way.

This program is specifically meant for general time preferences. As opposed to inputting specific days or meeting times throughout the month or year, each person's time preference 
is a reoccurring one, meaning if a time of Mon between 11:30 am - 12:30 pm is input, they are able and willing to meet at that time every week as part of their schedule.

## Features

1. User Data Card Page:
   A person's data card includes their name, an ID, and the various time preferences they have. This page allows the user of the program to input all this information

2. Instruction Page:
   A page in the program which contains instructions for the programs use

3. Scheduler Page:
   A page where the user can create various schedules based on preference. Options include selecting specific individuals or all people for scheduling,
   selecting different times and weekdays, and limiting the number of schedules to be displayed
