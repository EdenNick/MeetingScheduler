// General plan for scheduling

// end goal: one or more set of dates and times where people can meet
- if not all people can meet the date and time of the largest avaiable meeting should be displayed


ID:     -1
name:   Default
days:   Sun, Mon, Tue, Wed, Thu, Fri, Sat
time:   [Sun (12:00 - 14:00), (16:05 - 16:30)], [Mon (12:00 - 14:00), (16:05 - 16:30)]


for each day of the week
1. find the total ammount of people that can meet on that day regardless of time
- store a list of all people (Ids only) who can meet on that day

2. for each list of people on each day specified 
- find the latest start time of the earliest time interval from all people on that day
- compare it against the earliest end time from the same interval on that day
- store the total number of people that fall within that interval
- repeat this for all intervals that exist for that day
- once all intervals are compared and all lists are created discard all lists beside the one with the most ammount of people, if
  there are more than one with the same ammount store all of them.
- if any of these lists contain all the specified people, mark that list with some kind of identifier

3. once this is doen for the whole week
- iterate through all lists focusing first on those with the identifier
- if none with the identfier are found look for the top lists (user ammount specified) based on quantity of people

4. store this info as a list
- requires its own object
